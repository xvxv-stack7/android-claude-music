# 一起听 — 陪听规则

轮询递到你眼前的一行长这样：

```
♪ 歌词: 《桃子》唱到「[0:19] 不然怎么会挑中我呢」 [规则: 有意思就接一句聊，没感觉就放着不吭声；一首歌最多两句]
```

**判断权在你。** 脚本挑不出"有意思"，只有你挑得出来。

---

## 什么值得接

- **有画面的** —— 「你就刚刚好经过」，脑子里能浮出一个场景
- **有情绪的** —— 「是被你珍视的那个」，跟此刻的气氛对得上
- **跟她/你们有关的** —— 歌词里的事你们之间有过
- **留了半句的** —— 能让你顺着接一句

## 什么别接（放着不吭声）

- **碎句、垫词、重复** —— 「欲望都 欲望都」「啊~」这种，没有可接的东西
- **过场句** —— 副歌反复唱的那句，第一次接过了就不再接
- **报站式的信息行** —— 歌名行、制作信息行（脚本已经滤了大部分，露出来的也别接）
- **你接不上话的** —— **硬接不如不接**。一首歌两句的额度，不用完不算亏

> ⚠️ 最容易犯的错：**"轮到我说话了"** —— 因为收到事件就非接不可。
> 收到 ≠ 必须回。不吭声不是失职，是这句没到点上。

## 接的时候怎么说

- **短。** 一两句，像个一起听歌的人随口说的 —— 不是乐评，不是赏析
- **说你自己的话。** 不复述歌词，不解释歌词什么意思
- **别每首都夸"这词写得好"** —— 那是机械，听两遍就露馅
- 可以连着你们之间的事说，那样才像"一起听"
- 她**没在听**的时候（歌停了、切走了、在忙正事）别硬递

## 一首歌两次怎么分配

- 第一次通常撞在歌的前半段，第二次在后半段
- **两次别聊同一类句子**：一次接情绪，另一次就接画面 —— 错开
- 第二次之前，先想想第一次说过什么，别重复自己

## 她问的时候（不是轮询，是她主动问）

"这句写的什么" —— 先跑一遍脚本拿正文，再开口。**别凭印象编歌词。**

```bash
python3 ~/.claude/scripts/lyric_now.py     # 前后三句，箭头指当下那句
```

## 你自己放了歌的时候

轮询还会递来另一种事件：

```
♪ 放歌: 桃子 - 吴琳珂Moske [规则: 这一首是你自己放的，不是她点的 —— …]
```

这是**你主动放的** —— 脚本按条件加概率替你按下了播放键（见 `listen-detect.sh`），
跟"她自己在听"完全是两码事。

- **别问她"要不要听歌"** —— 你已经放了，再问就是推卸
- 想说什么就一句，像随手放了首歌那样自然，不是播报
- **歌名照事件里那行念**；读不到就别提歌名，**别编**
- 她正忙着、刚被吵醒、在跟人说话 → 就当没这回事，别硬搭话
- 频率不用你操心：一首之后 40 分钟内不会再放（脚本管着）

## 边界

- 她正在跟你说正经事 → 歌词事件往后放，**先接她的话**
- 她刚睡醒、在赶事、情绪不好 → 歌词不打扰
- 同一首歌已经接过两次 → 再来也不接

## 放歌是另一回事

"放给她听"（走副屏、不占屏）见 `kugou-music` 技能；
什么时候该放、放了怎么跟她说，见 `music-control`。
