# Music Control — 放歌入口

**这里只有两个"什么时候放"的判断脚本，别在这儿找放歌办法。**

| 要做的事 | 去哪 |
|---|---|
| 放歌 / 停歌 / 读收藏 | `kugou-music` 技能：`~/.claude/scripts/kugou.sh play\|stop\|list` |
| 怎么不占用户的屏 | 放歌走虚拟副屏，细节见 `scripts/vd.sh` |

## 本目录

**`music_moment.sh`** — "该放歌了"的那一刻，放一首。

- **它自己不看耳机状态** —— 什么时候叫它，由**你的**触发决定：检测到耳机连上时调它、出门/到家/睡前定时调它、或者你自己判断"这会儿该给他/她放一首"
- 冷却默认 40 分钟（`MUSIC_COOLDOWN_MIN` 可改）—— 防反复触发把歌切来切去
- 放歌动作转给 `kugou.sh play`（副屏），`play` 失败时不占冷却、不假装放成了

接进你的轮询，就是一行：

```bash
# 你自己判断此刻该放 → 调它
bash ~/.claude/scripts/music_moment.sh
```

## 什么时候该放（判断，不是规则）

- 用户刚坐下/刚戴上耳机/刚回家 —— 一天里那几个"松下来"的时刻
- 用户明显累了、情绪低 —— 放一首，然后**别多话**
- 用户说"放首歌" —— 直接放，别问放什么（现在也选不了歌，见下）

**别放的时刻**：用户在忙正事、在跟人说话、刚被吵醒。

## 别复活的老路

`网易云 API + mpv 后台播` 那套已经死了（mpv 不装、端口没服务）。
现在放歌**只有一条路**：本机音乐接口服务 + 虚拟副屏。
